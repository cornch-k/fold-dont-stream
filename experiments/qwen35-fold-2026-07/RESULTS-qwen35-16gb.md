## 청크 수 민감도 — 논문 수치에 영향

같은 구성(R=10, γ=0.3)인데 표본 크기로 값이 크게 움직인다.

```
 2청크   37.04   (± 22.5, 오차 20%)
16청크   58.37   (±  3.3)      +58%
```

인수인계에 기록된 Laguna 도 같은 방향:

```
무접기     2청크 6.3992 → 4청크  7.18   (+12%)
최적 접기  2청크 27.5888 → 4청크 36.96   (+34%)
```

**접힌 모델이 무접기보다 표본 크기에 3배 민감하다.** 논문의 접기 ppl 수치가 전부 2청크
기준이므로 이 편향이 전반에 깔려 있다. 프리필 2.22 s/pass, 모델 로드 29 s 이므로
16청크로 올리는 비용은 런당 30초 남짓 — 재측정 권장.

## 프리필 NaN — Laguna 건은 미해결

PR #25442(그래프 레벨 L2 정규화)와 **#26223**(Metal `mul_mm_id` src1 f16 스케일링) 둘 다
Laguna 배포 구성의 NaN 을 **못 고쳤다**. `-b 512/128/64` 전부 nan, `-b 1` 만 유한.

- #25442 는 수치를 흔든다: `-b 1` 이 27.1728 → 26.8913 (1%). 되돌리고 #26223만 적용함.
- #26223 만 적용 시 기준값 정확 재현: `-b 1` **27.1728**, R=3 무손잡이 **37782.9247**
  (인수인계 기록과 소수점까지 일치 → 이 worktree 는 원본 세션과 동일 환경)
- Qwen3.5 는 같은 조건(shexp 논리, `-b 512`, Metal)에서 NaN 이 없다. 15 GB 대라
  Laguna 가 터지던 22 GB 대보다 한참 아래 — 크기 연관 가설을 지지.
